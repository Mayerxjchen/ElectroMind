Small & embeddable

Session + Agent + tools — no file editor, no shell, no MCP. You own the loop.

Stream as it runs

Incremental output for chat UIs — wire up your own frontend when you are ready; the docs walk you through it.

OpenAI-shaped API

Works with OpenAI, DeepSeek, Ollama, vLLM, SGLang — any /v1/chat/completions compatible server.

A full agent in ~25 lines ​

Pick a provider tab, set the API key, save as demo.py, run python demo.py. The model can call your @tool and you read the answer from result.content.

python
import asyncio
import os

from pagent import LLM, Agent, Session, tool


@tool()
def get_weather(city: str) -> str:
    """Return weather for the city."""
    return f"Sunny in {city} today."


async def main():
    if not os.getenv("OPENAI_API_KEY"):
        raise SystemExit("Set OPENAI_API_KEY first.")

    agent = Agent(
        llm=LLM("gpt-4o-mini"),
        session=Session("You are helpful. Use tools when needed."),
        tools=[get_weather],
        max_turns=8,
    )

    result = await agent.run("What's the weather in Xiamen?")
    print(result.content)


asyncio.run(main())
