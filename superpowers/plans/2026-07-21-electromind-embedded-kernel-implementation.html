ElectroMind Embedded Agent Kernel Implementation Plan ​

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Turn ElectroMind into an independently installable product whose in-repository Agent kernel is a provenance-recorded derivative of pagent v4, while preserving Skills and Local/Docker/SSH execution behavior.

Architecture: electromind.app owns product configuration, CLI, diagnostics, rendering and approvals. electromind.kernel owns the Agent core, runtime, conversations, threads, Skills and stable facade; electromind.execution owns Sandbox implementations and the HPC job protocol. The migration first preserves pagent v4 behavior under the new package, then applies ElectroMind paths and layer boundaries in separately tested commits.

Tech Stack: Python 3.11+, uv/uv_build, asyncio, OpenAI-compatible providers, prompt-toolkit, pytest/pytest-asyncio/pytest-cov, ruff, Docker, asyncssh, TOML, JSONL/SQLite.

Global Constraints ​

  • Product display name is ElectroMind; distribution, import package and CLI are electromind.
  • Product version starts at 0.1.0; Python requirement is >=3.11.
  • The source baseline is commit ceba69b2e6e5eea99a0da3e9c3b573e6b1297d11, limited to the 56 files under src/pagentv4/ and the 23 tests/test_pagentv4_*.py files.
  • The final runtime dependency list must not contain pagent; no importable pagent, pagentv4 or top-level app package may remain.
  • Provenance names are allowed only in NOTICE.md, design/plan documents, Git history and source-boundary tests.
  • Product configuration is electromind.toml; user state is ~/.local/share/electromind, project state is <project>/.electromind, and environment override is ELECTROMIND_HOME.
  • The product must not read or create .pagent, ~/.pagent, PAGENT_HOME or pagent.toml.
  • API keys are never committed; the primary environment variable is ELECTROMIND_API_KEY.
  • Skills remain domain-neutral; no ai2-kit, Packmol or DeepMD workflow is hard-coded into the Agent loop.
  • Local, Docker, Podman and SSH Sandbox behavior is migrated; real Slurm submission is excluded. This plan creates only the JobExecutor protocol and models.
  • Tool permission mode defaults to prompt; Skills cannot bypass approval hooks.
  • Do not use git reset --hard, git checkout --, destructive cleanup, or delete the user's untracked pagent.toml.
  • Preserve unrelated user changes. Stage only the exact paths listed in each task.
  • Initial branch coverage must be at least 78%; core loop, approval and path code cannot be excluded to reach the threshold.
  • The current DeepSeek key must be revoked and rotated outside the repository before release verification.

File Responsibility Map ​

Product package ​

  • src/electromind/__init__.py: product version and stable top-level exports.
  • src/electromind/__main__.py: python -m electromind entry.
  • src/electromind/app/config.py: TOML layers, environment secrets and validated application configuration.
  • src/electromind/app/cli.py: argparse commands and exit-code mapping.
  • src/electromind/app/application.py: Runner lifecycle and command services.
  • src/electromind/app/repl.py: interactive input loop only.
  • src/electromind/app/render.py: terminal event rendering only.
  • src/electromind/app/permissions.py: product approval policy implemented with kernel hooks.
  • src/electromind/app/diagnostics.py: side-effect-free environment checks.

Embedded kernel ​

  • src/electromind/kernel/facade.py: supported kernel exports.
  • src/electromind/kernel/core/: messages, events, tools, AgentCore and provider protocol.
  • src/electromind/kernel/runtime/: Runner, loops, hooks, inbound control and run state.
  • src/electromind/kernel/conversation/: JSONL and SQLite persistence.
  • src/electromind/kernel/threads/: ThreadSpec and local thread implementation.
  • src/electromind/kernel/skills/: Skill parsing, discovery, installation prompt and use_skill.
  • src/electromind/kernel/tools/: generic tools such as web search.
  • src/electromind/kernel/adapters/: event/protocol adapters.
  • src/electromind/kernel/trace/: trace IO, viewing and export.
  • src/electromind/kernel/paths.py: ElectroMind state and configuration roots.

Providers and execution ​

  • src/electromind/providers/openai_compatible.py: concrete DeepSeek/Kimi/VLLM/SGLang/Ollama-compatible providers.
  • src/electromind/execution/sandbox/: Sandbox facade, policies, tools and Local/Docker/Podman/SSH backends.
  • src/electromind/execution/jobs/models.py: immutable HPC job value objects.
  • src/electromind/execution/jobs/protocol.py: asynchronous JobExecutor contract without a Slurm implementation.

Tests and delivery ​

  • tests/kernel/: migrated pagent v4 behavior tests.
  • tests/app/: product config, CLI, application, REPL, render and permissions tests.
  • tests/execution/: Sandbox and job protocol tests.
  • tests/integration/: Local/Docker/SSH product integration tests.
  • tests/fixtures/example-skill/: generic Skill fixture only.
  • scripts/check.sh: deterministic local/CI verification.
  • .github/workflows/ci.yml: Linux CI and Docker release gate.

def resolve_electromind_home(cwd: str | Path | None = None) -> Path:
    explicit = os.getenv("ELECTROMIND_HOME")
